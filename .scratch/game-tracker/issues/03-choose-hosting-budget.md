# Set the budget for the friends test

Type: grilling
Status: resolved
Blocked by: 01

## Question

Should the initial friends test use free service tiers only, or is there an
acceptable monthly budget? Establish the budget before selecting hosting,
account storage, and any email delivery service.

## Comments

Do not purchase services or enable billable subscriptions based on a planning
budget alone. Compare actual limits and onboarding requirements before choosing.

## Answer

The owner clarified that the application will be self-hosted on their server,
including user account records. The proposed managed-service budget question
does not apply to the selected deployment direction. No managed provider has
been selected or provisioned.

Establish the target server environment before recommending deployment tooling.
Any actual additional service or infrastructure costs should be evaluated only
if a concrete requirement emerges.
