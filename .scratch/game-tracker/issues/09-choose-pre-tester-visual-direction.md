# Choose the visual improvements for the next milestone

Type: grilling
Status: open
Blocked by: 08
Parent: [Game-tracker planning map](../map.md)

## Question

Given the selected user need and feature shortlist, which changes to the existing
purple cinematic design would make the experience feel finished before testers
arrive, and which screens and visual criteria bound that work?

The owner's feature direction is now richer catalog exploration: filtered/sorted
search and company descriptions with developed/published games. Include these
surfaces and the game-to-company-to-game journey when discussing visual
hierarchy; do not base the visual milestone on the earlier Library-first proposal.

## Context

Prototype D with C's purple palette is the accepted direction: cinematic hero,
desktop sidebar, compact discovery cards, separate My Library, and responsive
mobile navigation. Detailed polish was deferred, and the owner now wants it
before tester invitations. A wholesale redesign has not been requested.

## Discussion requirements

- Ask what feels unfinished in the real app and what should be retained.
- Examine representative desktop/mobile screens when available before treating
  an assumed visual weakness as a finding.
- Prioritize hierarchy, artwork, density, typography, and action placement
  against the selected journey; agree which surfaces need changes.
- Preserve keyboard and phone usability, readable contrast, and honest
  loading/empty/error/stale states as acceptance requirements.
- Define visible success criteria and a bounded review set. Avoid a theme system,
  branding project, or decorative additions without a concrete benefit.
- This ticket decides direction only. Do not build a prototype or modify the app
  during the current plan-only continuation.
