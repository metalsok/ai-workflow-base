# Game tracking

A personal game catalog and tracking application. These terms describe how a
person organizes games in their own lists.

## Language

**Game**:
A standalone catalog title, including a remake or remaster as a distinct title.
DLC, mods, bundles, and special/collector editions are outside the initial catalog scope.

**Play status**:
A user's current relationship to a tracked game: Want to play, Playing,
Completed, or Stopped playing. A game has one current play status per user.

**Want to play**:
A game the user intends to play.

**Playing**:
A game the user is currently playing.

**Completed**:
A game the user considers finished.
_Avoid_: Played, when referring specifically to completion

**Stopped playing**:
A game the user started but stopped playing without completing it.

**Played**:
A combined view of games with the status Playing, Completed, or Stopped playing.
_Avoid_: Completed, when referring to all games a user has started

**Company**:
An organisation credited on games.

**Developer**:
The role of a company that made a specific game.

**Publisher**:
The role of a company that released a specific game. Publishing a game does not mean making it.
_Avoid_: Developer, when the company only published the game

**Parent company**:
The company that currently owns another company.

**Studio**:
A company owned by a parent company.
_Avoid_: Studio, for a developer the publisher only worked with

**Worked with**:
A publisher's connection to the developers of games it published, without ownership.
